# HRI의 실제 반례

- 2026-10-20의 한 번/두 번/세 번 터치와 쓸기가 모두 TOUCH 상태로 관측되고 채널 배열이 구분 근거를 주지 않았다. 상태 유지 시간을 세어 지원하지 않는 제스처를 복원했다고 주장하지 않는다.
- 2026-11-09 밀림 기록에서는 가벼운 접촉에도 큰 가속도 차이가 나타났고, 강한 기준 후보로 쓰려던 구간에 MC 모드 전환과 표본 공백이 있었다. 임의 threshold를 실기 보정 완료 값으로 승격하지 않는다.
- 같은 날 두 큰 피크 사이 약 2.4 s에 두 번째 반응이 없었던 기록은 유효 출력 후 재보정 구간과 겹쳤다. cooldown 축소 후보는 잔류 흔들림을 추가 반응으로 세는 반례가 있었다. 고정 지연 축소만으로 해결되지 않았다.
- 가속도 벡터 차이는 중력 방향 변화, 자세/기저 진동과 섞인다. 천천히 지속되는 힘은 IMU 변화만으로 감지하지 못할 수 있다.
- 근접 box 면적 보정은 당시 로봇 자세와 사용자 위치의 경험적 기준이다. 다른 키, 가림, 렌즈 각도에서는 같은 area ratio가 같은 거리가 아니다.
- 서비스 active나 wav 생성 완료는 실제 센서 자극→중재→음성/얼굴 출력 성공이 아니다. 출력 요청 횟수와 현장 청취/표시를 별도 기록한다.
