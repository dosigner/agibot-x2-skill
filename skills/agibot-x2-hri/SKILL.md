# X2 터치와 밀림 반응

## 입력이 실제로 알려 주는 것

[실기 반례와 보정 한계](references/lessons.md)를 먼저 읽는다. TouchState의 enum 존재는 장치가 해당 제스처를 분류한다는 뜻이 아니다. IMU 가속도 변화는 외력이나 접촉 강도 정답이 아니다. 영상 box 크기는 보정된 거리 센서가 아니다.

- **터치:** 반복되는 같은 상태를 이벤트 횟수로 세지 않는다. 실제 한 번/두 번/쓸기 자극과 수신 event/channel을 대조하고, 구분되지 않으면 `contact_only`로 처리한다. injected/demo 출력과 실제 접촉을 표시한다.
- **밀림:** 원하는 MC 모드, 플레이어 상태, 신선한 IMU/MC를 같은 시간창에서 확인한다. 안정 구간 기준 벡터와 가속도 차이, 관측 공백, 각속도와 모드 전환을 함께 기록한다. 기준 자세가 바뀌면 다시 보정한다. 안정 구간 벡터를 빼는 것은 기준 대비 변화량이며 중력 제거가 아니다. 기울기만 바뀌어도 센서 축의 중력 성분이 달라지므로, 실제 중력 보상에는 같은 시각의 자세와 좌표/부호 계약이 필요하다. 이 근거가 없으면 중력 제거 또는 외력 환산으로 표시하지 않는다.
- **재반응:** peak window, cooldown, 안정 재보정을 따로 둔다. 대기 시간만 줄이면 잔류 진동이 두 번째 접촉으로 오인될 수 있다. 한 번/두 번 접촉 기록을 모두 replay해 반례를 유지한다.
- **근접:** box area ratio와 화면 위치를 현장 자세에서 보정하고 hysteresis 및 재진입 조건을 둔다. 카메라 단절은 사람이 나갔다는 증거가 아니다. 자세/해상도/시야 변경 시 보정을 무효화한다.

출력 연결은 기존 Audio Coordinator와 얼굴 소유권을 사용한다. 감지 중지와 모션 정지는 다른 동작이다. 정확히 라벨링한 시험에 근거하기 전 임계값을 힘 단위 N이나 보편적인 약/강 접촉 기준으로 설명하지 않는다.

## 완료 기준

원본 기록, 현장 라벨의 정밀도, 보정/검증 데이터 분리, false positive/누락, 반응 지연과 재보정 시간을 보고한다. 접촉 완료를 나중에 받은 응답만으로 밀리초 단위 onset을 만들지 않는다. 모드와 표본이 신선하지 않으면 새 반응을 차단하는 경계를 검사한다.

근거의 날짜, 출처 및 재확인 조건은 [근거 목록](references/evidence.md)을 따른다. 과거 보고서의 확인과 이번 실행의 확인을 분리해서 보고한다.
