# 요청별 완료 조건

## 막연한 개발 요청

사용 상황과 원하는 결과부터 묻는다. 이후 구현에 필요한 입력, 처리, 출력, 시작·종료·오류 조건, 제약·성공 기준, 변경 대상을 확인한다. 답을 이미 받은 항목이나 기존 코드에서 확인되는 항목은 반복하지 않는다. 모든 항목을 설문처럼 한 번에 요구하지 않는다. 결정이 필요한 동안 프로젝트 구조와 관련 정의 등 독립적인 조사는 진행할 수 있다.

## 학습

사용자가 지목한 기능의 역할과 개념, 토픽/서비스/Action 및 메시지의 관계, 데이터가 흘러가는 순서를 설명한다. 지원되는 화면에서는 Mermaid, 아니면 텍스트 화살표나 표를 쓴다. 파일 생성과 언어 선택은 설명의 선행 조건이 아니다. 제조사 문서에 없는 내부 SLAM·인지 알고리즘은 확인된 구현처럼 설명하지 않는다.

RGB-D 설명에서 사용하는 흐름의 예:

```text
컬러 Image + 컬러 CameraInfo ─┐
깊이 Image + 깊이 CameraInfo ─┼→ 시간 확인 → 정합·좌표 변환 → 사용자 처리
센서 간 TF/기체 보정 ─────────┘
```

깊이 encoding은 저장 형식이다. 거리 단위·스케일은 드라이버/인터페이스 계약과 별도로 확인하며 encoding만으로 확정하지 않는다. 역투영 식은 카메라 모델과 raw/rectified 상태를 명시하고 왜곡 처리 및 해당 CameraInfo의 K/P를 확인한 뒤 제시한다. 실제 정합 여부는 수신 메시지와 보정으로 확인한다. 도식의 사용자 처리는 새 설계이며 제조사의 내부 파이프라인을 나타내지 않는다.

`X=(u-cx)Z/fx`, `Y=(v-cy)Z/fy`를 제시한다면 식 바로 옆에 **왜곡 처리가 끝난 pinhole 좌표, 광축 방향의 깊이 Z, 그 영상에 대응하는 보정 행렬을 가정한 식**이라고 명시한다. raw/fisheye 영상이나 센서로부터의 직선 거리에는 그대로 적용할 수 없다. 개념 설명에 계산식이 필요 없으면 생략한다.

## 기존 파일 수정

대상 파일, 호출부, 빌드 설정과 기존 테스트를 읽는다. `.py`면 Python으로, C++ 소스면 기존 C++ 기준으로 진행한다. 저장 기능이면 경로·파일 형식·저장 주기·동기화·실패 정책 중 결정되지 않아 구현을 바꾸는 항목만 확인한다. 문맥에서 합리적으로 정할 수 있는 낮은 영향의 세부사항은 설명하고 진행한다.

파일 형식과 저장 위치를 일괄적으로 작은 결정으로 취급하지 않는다. 깊이 정밀도·메타데이터·후속 프로그램 호환성·덮어쓰기·용량에 영향을 주는데 근거가 없으면 확인이 필요하다. 이미 정해진 형식 안에서 임시 파일명처럼 결과 의미를 바꾸지 않는 세부사항은 합리적으로 정할 수 있다.

요청한 변경을 실제 파일에 반영하고 가능한 검사를 수행하면 완료다. 수정안을 설명하는 것만으로 완료하지 않는다. SDK가 없으면 순수 로직 테스트, Python 구문 검사, 코드/정의 대조 등 가능한 검증을 하고 ROS 빌드·실장비 수신은 미실시로 남긴다. 임의 SDK 스텁의 컴파일을 실제 SDK 빌드로 보고하지 않는다.

## 새 구현

언어를 요청이나 프로젝트에서 결정할 수 없으면 C++/Python을 질문한다. 기존 저장소 구조를 확인하고 독립 스크립트/ROS 패키지/기존 노드 중 결과물 범위가 구현에 영향을 줄 때 명확히 한다. 확인된 토픽·타입·필드·단위·QoS만 사용하고 메시지 정의가 없으면 해당 부분을 미확인으로 둔다. 임의로 표준 타입으로 대체하지 않는다.

## 자체 알고리즘

예: 카메라·IMU 위치 추정은 4.1과 4.2를 함께 선택한다. 제조사 SLAM을 이용할 때만 5.1을 추가한다. 입력 센서/주기/시간 기준, 좌표계/보정, 출력 자세·속도·공분산, 초기화·재설정, 데이터 유실·추적 실패, 정확도·지연 목표를 정한다. 사용자가 C++을 지정했다면 언어를 묻지 않는다.

관측·동기화 → 전처리 → 추정 상태와 업데이트 → 유효성 검사 → 출력의 구조를 설계하고 추정기와 ROS 입출력을 분리해 구현한다. 관측 가능성, IMU 바이어스·중력 처리, 시차/스케일 가정을 명시한다. 기록 데이터·합성 데이터로 검증할 항목과 실제 센서 검증을 분리한다. SDK 구독 예제로 알고리즘 구현을 대신하지 않는다.
