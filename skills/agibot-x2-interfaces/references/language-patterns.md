# C++·Python 적용

각 기능의 공식 예제 링크에서 선택한 언어의 관련 절만 읽는다. 기존 Python 파일에는 현재 rclpy 구조를, C++에는 현재 rclcpp·CMake 구조를 유지한다. 새 구현의 언어가 미정인 경우에만 질문한다.

제조사 타입은 실제 설치된 aimdk_msgs 패키지와 생성된 import/include 경로를 확인한다. 원문의 오기로 보이는 필드도 설치된 정의와 대조하기 전 바꾸지 않는다. 표준 ROS 타입으로 임의 대체하지 않는다. 웹 링크를 찾았다는 사실만으로 API 이름이나 완전한 타입을 확정하지 않는다.

조회 코드에 서비스 호출·모드 전환·명령 발행을 자동 추가하지 않는다. 실제 SDK가 없으면 가능한 문법 검사와 순수 로직 테스트를 수행하고 실제 SDK 빌드로 표현하지 않는다.
