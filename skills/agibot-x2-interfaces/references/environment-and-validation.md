# 환경과 모션 없는 검증

현재 셸의 ROS 배포판, 실제 인터프리터·패키지 경로·버전과 작업 대상이 PC인지 로봇인지 확인한다. 사용자에게 이미 받은 연결 정보는 재질문하지 않는다. 경로, IP, 설치 SDK나 ROS 버전을 추측하지 않는다.

공식 문서의 계약과 설치된 `.msg/.srv/.action`을 대조한다. 실행 환경 확인에는 `command -v ros2`, `printenv ROS_DISTRO`, `ros2 pkg prefix aimdk_msgs` 같은 읽기 전용 명령을 선택해서 사용할 수 있다. 명령 또는 SDK가 없으면 순수 로직 테스트와 소스 검토를 계속하며 빌드 미실시를 명시한다.

모션 없는 장치 접근은 허용된다. 먼저 생성자·초기화·콜백·timer·종료·launch 포함 파일까지 읽는다. 모션 발행, 서비스·Action, 제어 활성화, 관련 모드 전환이 섞여 있으면 그 경로를 실행하지 않는다. 예제 7처럼 센서 이름이 붙은 코드는 실제 발행 동작과 기체 지원을 특히 확인한다.

수신 대상이 확인되면 실제 타입·QoS·발행자·시간·좌표계·인코딩을 검사하고 수신 횟수·제한 시간을 둔다. 패키지 문법 검사, 실제 클라이언트 호출, ROS 빌드, 센서 수신은 별도 결과다. 수행한 명령과 근거만으로 결과를 설명하며 모션은 이 스킬의 실행 범위에서 제외한다.
