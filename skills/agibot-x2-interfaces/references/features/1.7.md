# 1.7 LinkCraft Actions

필요한 공식 절을 열어 현재 계약을 확인한다. 이 공개판은 제조사 메시지 정의·엔드포인트 표를 포함하지 않는다.

## 공식 자료

- [공식 인터페이스 1](https://x2-aimdk.agibot.com/en/latest/Interface/control_mod/linkcraft.html)
