# 관절 기준 확인

[공식 관절 범위](https://x2-aimdk.agibot.com/en/latest/about_agibot_X2/joint_name_and_limit.html)를 열고 **X2 Ultra Edition** 열을 확인한다. 이 파일에는 제조사 수치표를 복제하지 않았다. [좌표계·URDF·보정 안내](https://x2-aimdk.agibot.com/en/latest/about_agibot_X2/coordinate_system.html)와 실제 설치 모델도 대조한다.

관절 이름, 좌우, 축, 영점, 부호, 단위를 메시지에 연결한다. 문서의 관절 번호를 배열 인덱스로 사용하지 않는다. N/A를 0도로 변환하지 않는다. 출처가 충돌하면 기체 식별·SDK·펌웨어·URDF·제어기 설정을 조사하고 해결되지 않은 제한값의 적용을 보류한다.

범위 초과의 처리 정책은 사실 확인 후 정한다. 목표값을 알리지 않고 임의로 자르지 않는다. 시작·끝점이나 유한한 샘플이 유효하다는 사실만으로 연속 궤적을 보증하지 않는다. 보간식의 극값·구간 경계 등 방법에 맞는 검사를 사용하고 미검증 범위를 명시한다.

공식 표와 설치 정의를 확인할 수 없으면 숫자를 제안하지 않는다. 가능한 구조 설계와 오프라인 로직 작업은 계속한다. 관절 범위 검사는 충돌·안정성·실장비 동작 검증을 대신하지 않는다.
