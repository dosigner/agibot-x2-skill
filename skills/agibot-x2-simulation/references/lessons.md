# 시뮬레이션에서 보존할 실패 지식

- 초기 하체 PPO pilot은 실행 루프/저장/strict reload를 검증했지만 다수 낙상과 짧은 episode가 남았다. `hardware_eligible=false`를 학습 exit code로 뒤집지 않는다.
- 새 하체 12축 action/상체 19축 계약과 기존 HoloMotion 29축 계약은 별개다. 학습 구조가 비슷하다는 이유로 checkpoint를 호환시킬 수 없다.
- MuJoCo 4.0.1 TrackingSim에서 실제 영상의 원본 기준은 0.62 s에 골반 높이 오차가 기존 0.25 m 한계를 넘어 종료된 사례가 있다. 이후 기준 재구성/제어/CPU 학습 후보도 원래 2.60 s 목표를 달성했다는 근거가 없었다. 이 기록을 모든 영상의 성능으로 일반화하지 않는다.
- 기준의 발 접지, 관절 속도, 근사 ZMP를 개선해도 실물 및 실제 rollout이 안정된다고 보장되지 않았다. 원본 사람 대응점 오차가 오히려 늘 수 있으므로 접지 지표와 모션 충실도를 동시에 보고한다.
- MPC candidate clone과 실제 rollout 불일치가 의심되면 저장된 동일 action을 새 단일 환경에 replay한다. 오차가 작아도 제어기 예측 모델/비용함수/기준 자체가 옳다는 뜻은 아니다.
- 원래 초기속도를 0으로 두는 실험은 영상 측정이 아닌 가정이다. 시작 frame index를 옮기거나 retiming하면 별도 평가다.
- 오래된 체크포인트/모델 파일은 경로만 같아도 내용이 달라질 수 있다. 결과마다 입력/모델/정책 hash와 실제 import/엔진 버전을 남긴다.

원본 contact reconstruction 보고서는 계속 갱신될 수 있다. 여기에 적힌 종료 시간은 특정 시험의 예이며 최신 최장 성능 표가 아니다.
