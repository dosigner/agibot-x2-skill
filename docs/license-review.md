# 라이선스 조사와 공개 범위

확인일: 2026-10-02. 사용자는 공개 배포를 선택했고 제조사 원문을 공식 링크로 대체하는 변경을 승인했다.

| 대상 | 확인한 내용 | 이 패키지의 처리 |
|---|---|---|
| 공식 X2 URDF 저장소 | [Mulan PSL v2](https://github.com/AgibotTech/agibot_x2_urdf/blob/575cc6b988f976c23550e0db85aa1e5475d3652d/LICENSE) | 새로 작성한 코드·설명에 같은 라이선스 채택. URDF 파일은 포함하지 않음 |
| X2 AimDK 웹 문서 | [홈](https://x2-aimdk.agibot.com/en/latest/), [센서 정의](https://x2-aimdk.agibot.com/en/latest/Interface/hal/sensor.html), [개발 유의사항](https://x2-aimdk.agibot.com/en/latest/end_notes.html)의 All Rights Reserved 표기 | 추출물 재배포 허가를 확인하지 못해 메시지 정의·계약표·관절/FOV 표·HTML 제외 |
| 작성한 스킬과 도구 | 원래 작성한 지침·코드·분류·링크 색인 | LICENSE와 출처 고지를 포함해 배포 |

“제조사 자료”는 AGIBOT이 작성한 문서·메시지 정의·기체 사양표를 뜻한다. 다른 공식 저장소에서 라이선스를 찾았다는 이유만으로 해당 웹 문서에도 같은 조건이 적용된다고 판단하지 않았다. 이 조사는 확인한 출처의 표시와 배포 구성을 기록한 것이다.

비공개 GitHub 저장소도 소유자나 초대받은 협업자는 인증 후 clone할 수 있다. HTTPS는 PAT 또는 자격증명 관리자를, SSH는 등록된 SSH 키를 사용할 수 있다. 비공개 URL을 아는 것만으로 접근 권한이 생기지는 않는다. [GitHub 공식 원격 저장소 안내](https://docs.github.com/en/get-started/git-basics/about-remote-repositories).
